# Lessons (the long-term memory of the simulator)

Rules for this file:

- At most **40 bullets**. Each bullet is one line: the lesson, then (evidence: dates or numbers).
- **Only the Saturday review edits this file.** Daily and hourly routines read it and never change it.
- The review adds a bullet only when the same thing showed up on several days, merges bullets that say the same
  thing, and deletes the weakest bullet when the file would pass 40.
- A lesson can make the system more careful. It can never loosen a rulebook rule (docs/RULEBOOK.md); loosening
  needs the owner's approval.
- Numbers only as facts. No guesses about the future.
