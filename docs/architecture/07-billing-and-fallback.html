Billing and fallback: what happens when credits run out

Routines check their billing source each run. The engine never depends on any of this.
Paper trading only · no real money

1 NORMAL

Billing source: promotional cloud-session credits (until 5 Nov 2026)

  • All routines run as designed
  • Opus thinks at 08:50, in the fast lane, and on tough incidents
  • Alerts by Gmail

2 THRIFT

Billing source: Claude plan limits (from 5 Nov 2026)

  • Hourly run uses Sonnet only
  • Fast lane at most 2 runs a day
  • Weekly review is shorter
  • Same safety rules, less thinking

3 FALLBACK

Claude cannot run at all (limits used up or an outage)

  • Healthcheck notices routines_silent
  • A GitHub workflow uses the DeepSeek key
  • Alerts go out as a GitHub issue email

What costs what
