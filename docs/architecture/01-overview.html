How the whole system fits together

Prices feed a rule-based engine. Claude routines advise through files in the repo. You read one email a day.
Paper trading only · no real money
1 · Data

Prices

Yahoo Finance (.NS), every 60 seconds: GOLDBEES, SILVERBEES, HINDCOPPER

News

Google News RSS, RBI and Fed pages, every 2 minutes. Treated as untrusted text.

Macro and calendar

DXY, US 10-year yield, USD/INR. Event dates (CPI, FOMC, RBI) in state/events.json

2 · Actions

The Engine only thing that trades

market-hours.yml ticks every 60 s, 09:15 to 15:30 IST (about 375 checks a day).

  • Fixed rules, no AI, never waits for Claude
  • Floor, stops, tripwire, buys, sells
  • Writes one plain-English reason per decision
  • Wakes the fast lane on a price shock or big news

Watchdog

every 10 min: health check, restarts the engine if it stopped

incident.yml

when a run fails: opens an alert, may wake the incident routine

reminders.yml

hourly, 24/7: re-sends an unacknowledged HIGH alert

archive.yml

first Sunday of the month: gzips old logs, keeps repo small

tests.yml

pytest on every push and before every trading day

Fallback workflow

DeepSeek sets the bias and writes the summary if Claude is silent

3 · Repo

memory/

incidents/

5 · You

GitHub

Merge a pull request = approve a code fix. Comment ack on an issue.

You, the owner

Read one email a day. Decide only what is asked.

Gmail (one address only)

"Metals Daybook" emails: daily report, alerts, weekly note.

Daybook Inbox

Accept or Reject, with a reason box.

The engine decides

  • Every buy, sell and size
  • The Green Guard floor and tripwire
  • Re-checks all advice against the rulebook; advice that breaks a rule is ignored and logged

Claude routines advise

  • A bias per metal: favour, neutral, block
  • Calendar events, notes, memory
  • Defensive fast-lane actions
  • Never: buy, set a size, loosen a stop, touch the floor or caps

You approve

  • Any code or rule change (merge a PR or tap Accept)
  • Anything that adds risk needs a commit to config/params.yaml
  • An email reply can only say "ACK", never approve code
